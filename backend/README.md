# backend: Supabase

Design and security model: [docs/03-backend.md](../docs/03-backend.md).

```bash
cp .env.example .env        # fill SUPABASE_URL, SUPABASE_SECRET_KEY, DATABASE_URL
npm install
npm run db:migrate          # apply supabase/migrations/*.sql
npm run db:test             # 30 RLS checks (inside a rolled-back transaction)
```

- `supabase/migrations/0001_init.sql`: schema, constraints, indexes, triggers, RLS, storage buckets
- `supabase/migrations/0002_seed.sql`: built-in vehicles and synthetic cycles (generated by `npm run db:seed:gen`)
- `supabase/migrations/0003_harden_functions.sql`: pins function search paths
- `scripts/`: migration runner, RLS test suite, seed generator, e2e test-user helper
